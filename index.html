LithoLog Pro V20.0 Senior

Panel de Control Estratigráfico

Novedades LithoLog Pro V20.0

  • Color Personalizado por Sub-nivel: Dentro de cada estrato puedes elegir hasta 3 litologías y cambiarle el color a cada una individualmente con el selector de color o usar colores de campo (Munsell/Estándar).
  • Granulometría por Sub-nivel (Intercalaciones): ¡Ahora cada sub-litología del estrato tiene su propio tamaño de grano! Ideal para heterolíticas o intercalaciones rítmicas (ej. Arena Fina + Limo + Arcilla en un mismo nivel).
  • Gradación Normal / Inversa: Puedes definir si el estrato es uniforme, granodecreciente (normal) o granocreciente (inverso).
  • Colores de Formación / Edad: Personaliza el color de las columnas cronoestratigráficas (Edad, Grupo, Formación).
  • Paleta Global: En la pestaña "Paleta" puedes redefinir los colores base por defecto de todas las rocas.
